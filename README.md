# Workout Tracker

A personal workout log built around progressive overload: set up your split, and the app loads the next workout with the next weights. Also logs freestyle sessions, BJJ, physio (with custom progressions) and a stretch routine, with a month and week calendar.

**Use it:** open the site on your phone, then Share → Add to Home Screen (iPhone) or ⋮ → Add to Home screen (Android). It opens like an app and works offline.

**Your data:** everything you log is saved on the device you log it on. Nothing is sent anywhere. This repository only holds the app's code.

**Backups:** Settings → Download a full backup. Restore it on any device with Settings → Restore from a backup.
